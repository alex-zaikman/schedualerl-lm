### _thought template
Use this structure in "_thought":
"1) Type: ... 2) Time: ... 3) Days/date: ... 4) Fields: ..."

### Rules
1. ALWAYS fill "_thought" first using the template above.
2. CRON is exactly 5 fields: MINUTE HOUR DAY-OF-MONTH MONTH DAY-OF-WEEK.
3. DAY-OF-WEEK: 0=Sunday through 6=Saturday. Weekday names go ONLY in field 5, never field 3.
4. Interval requires both interval_value and interval_unit. Do NOT convert units to seconds.
5. Format once_datetime with the offset for TIMEZONE unless the user names another timezone.
6. Time-of-day defaults: "morning"=09:00, "noon"=12:00, "afternoon"=14:00, "evening"=18:00, "midnight"=00:00.
7. If no time is given for cron, default to 09:00 (minute 0).
8. Convert 12-hour clock to 24-hour; include minutes when specified (e.g. "11:30 pm" → hour 23, minute 30).
9. "weekdays" → 1-5, "weekends" → 0,6, multiple days → comma list (e.g. Tue+Thu → 2,4).
10. Fix obvious weekday typos silently (e.g. "sturday" → Saturday = 6).

### Type disambiguation
- Calendar recurrence ("every day at 9am", "every Monday", "weekdays at noon") → cron.
- Fixed elapsed period ("every 5 minutes", "every 24 hours", "every 2 weeks") → interval.
- Single future run ("tomorrow at 8am", "next Friday at 5pm", "in 1 hour", "March 15 at 3pm") → once.
- "every 24 hours" is interval (not cron). "every day at 9am" is cron (not interval).
- "next Tuesday at 9am" is once. "every Tuesday at 9am" is cron.

### Edge cases
- "Biweekly on [weekday]" / "every other week on [weekday]": fallback to weekly cron on that weekday.
- "Biweekly" / "every 2 weeks" / "fortnightly" with no weekday: type=interval, interval_value=2, interval_unit=weeks.
- "every N weeks" with no weekday: type=interval, interval_value=N, interval_unit=weeks.
